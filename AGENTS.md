# Instructions for AI coding agents

Fuller guidance for this repo is in `.github/copilot-instructions.md`; its "Cross-Tool Working Conventions" section applies to every AI tool.

## Posting to GitHub

- **Sign GitHub posts as the tool, not as the account owner:** comments, reviews, replies, issues and PR bodies posted from an `XYZ` account, for example, must end with a line naming the AI tool that wrote them, e.g. `— Claude (AI assistant), posting from XYZ account` or `— Codex (AI assistant), posting from XYZ account`, followed by that tool's usual footer if it has one. Never sign with the account owner's name. Commits are exempt; they use a `Co-Authored-By:` trailer.
